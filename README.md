# End-to-End MLOps Pipeline

This project implements a complete **MLOps pipeline** covering the full machine learning lifecycle, from data ingestion to model deployment and monitoring in production.

## Project Overview

The goal of this project is to simulate a real-world production MLOps system and practice industry best practices for building, deploying, and maintaining ML models.

## Key Components

- **Docker & Docker Compose** → containerization and environment setup  
- **Data Ingestion Pipeline** → automated data loading and validation  
- **Feature Store (Feast)** → centralized feature management  
- **MLflow** → experiment tracking and model registry  
- **Model Serving API** → deployment of trained models  
- **Monitoring (Prometheus, Grafana)** → system and model observability  
- **Drift Detection (Evidently AI)** → data and model performance monitoring  
- **CI/CD (GitHub Actions)** → automated testing, validation, and deployment  

## ML Lifecycle Covered

1. Data ingestion  
2. Data validation  
3. Feature engineering  
4. Model training  
5. Model tracking & registry  
6. Deployment  
7. Monitoring & drift detection  
8. Continuous retraining

## Goal

To build a production-like MLOps system and understand how machine learning models are managed in real-world environments.
